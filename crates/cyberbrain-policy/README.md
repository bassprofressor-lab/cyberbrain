# cyberbrain-policy

The compliance subsystem: egress register, audit chain, pii gate, retention, profiles.

A library crate of [Cyberbrain](https://crates.io/crates/cyberbrain), cited, trust-tiered,
local-first memory for AI coding agents. It is published so the binary can be, and its API is
shaped for that binary rather than for general use; expect it to change with the tool.

Repository, screenshots and specification:
<https://github.com/bassprofressor-lab/cyberbrain>
